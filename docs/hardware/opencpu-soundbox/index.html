Device Architecture

Cost Engineered Out, Security Engineered In

Four subsystems take a commodity 4G module stack and turn it into a payments-grade merchant device.

Module 01 // The BoM Breakthrough

Sub-₹600 Through Architectural Subtraction

Commercial payment soundboxes carry redundant silicon: an external applications MCU, a separate cellular module, a tuned FPC antenna, and licensing for a closed RTOS. The Gajalogic design collapses all four: the Air780E runs LuatOS directly as the OpenCPU application host, the LE271-IN provides single-mode Cat-1 connectivity sized for payment traffic, and an FR4 PCB trace antenna replaces external antenna hardware entirely.

OpenCPU (No External MCU)LuatOS RuntimeFR4 Trace Antenna
Module 02 // Profitability at the Edge

Merchant Unit Economics That Close

When the hardware floor drops from ₹3,000+ to under ₹600, soundbox-led UPI Acquiring becomes viable for small-ticket merchants — kirana stores, street vendors, single-counter retailers. The device pays for itself in weeks of MDR-equivalent economics rather than years, expanding the addressable merchant base by an order of magnitude.

Module 03 // Integrated PQC-Ready Security

Secure Elements Sized for the Quantum Decade

The on-board secure element stores device identity keys and payment credentials with memory headroom for lattice-based algorithms. As NPCI and RBI guidance hardens, fleet firmware updates swap the cryptographic profile without touching hardware.

Hardware Key IsolationLattice-Sized StorageOTA Crypto Profile Swaps
Module 04 // Fleet Operations

LuatOS OTA & Remote Key Rotation

Every device is a first-class fleet citizen: LuatOS firmware updates roll out over 4G in staged waves, key rotation executes remotely through the secure element, and device health telemetry streams back into the acquiring switch’s observability stack.
