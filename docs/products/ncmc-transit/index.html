Commuter turnstiles in Delhi, Mumbai, Bengaluru, and Chennai metros experience 1,200+ passenger taps per gate per hour. Module 02 // Dual-Mode Offline Stored Value Ledger

Zero-Leakage Offline Wallet Reconciliation

Buses and underground metro stations frequently lose 4G/5G and wired network connectivity. Our offline stored value ledger synchronizes batch transaction journals to central host clearing nodes upon reconnect with zero financial leakage and cryptographic non-repudiation.

Module 03 // PQC-Ready Smart Card Silicon R&D

Post-Quantum Defense on Constrained Silicon

Smart card microcontrollers have severe constraints: typically < 64 KB of EEPROM and 8 KB of RAM. Standard PQC signatures (Dilithium / Falcon) exceed these buffers. Gajalogic leads R&D into stateful hash-based signatures and memory-optimized ML-KEM profiles engineered specifically for physical transit smart cards.

Module 04 // Central Automated Transit Clearing House

Multi-Modal Fare Settlement Engine

Aggregates commuter taps across metro lines, feeder bus networks, and automated toll plazas. Automatically executes fare rules, peak/off-peak discounts, and daily multi-operator settlement with participating transit acquirer banks.

Silicon R&D // Post-Quantum Smart Card Cryptography

PQC Architecture for Memory-Constrained Silicon

While server-class cloud environments can easily process multi-kilobyte post-quantum keys, physical transit cards (contactless dual-interface JavaCard/NATIVE smart chips) possess severe execution bounds: typically 32 KB to 64 KB of persistent EEPROM and ultra-low clock speeds.

Gajalogic's silicon cryptography R&D team has engineered a compact hybrid stateful hash / compressed lattice verification engine that fits inside an unprecedented 48 KB card footprint. Turnstiles verify authenticity in under 80 milliseconds of NFC RF field contact, ensuring sovereign transit infrastructure remains secure against future quantum cloning devices.
