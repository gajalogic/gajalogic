Blueprint 02

Hybrid PQC Handshake Flow

The exact sequence of the X25519 + ML-KEM hybrid exchange and ML-DSA verification at the edge.

pqc-handshake.mmd Sequence diagram — matches the sandbox visualizer 
sequenceDiagram
  participant C as Counterparty / NPCI Rail
  participant G as Gajalogic Edge
  participant H as HSM (Thales Luna)
  C->>G: TLS ClientHello (hybrid offered)
  G->>C: ServerHello + X25519 share + ML-KEM-768 encapsulation
  C->>G: ML-KEM ciphertext + classical signature
  G->>H: Verify ML-DSA-65 / RSA chain
  H-->>G: Attestation OK (QRNG-sourced keys)
  G->>C: Session established - hybrid secrets derived
  Note over C,H: PQC overhead < 1 ms P99 - classical ciphers never removed first
